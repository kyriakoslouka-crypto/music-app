# Διορθώσεις μετά το preview.43

Η έκδοση παραμένει 0.5.0. Οι δοκιμές του preview.43 δεν θεωρούνται αυτομάτως αποτελέσματα του νέου κώδικα.

## Όρια εξέτασης

Η διεπαφή επέλεγε exam ή practice χειρισμό με βάση το ExamEngine.Running. Μόλις έληγε ο χρόνος, το Running γινόταν false πριν εκτελεστεί ο UI timer. Η υποβολή μπορούσε έτσι να καταγραφεί ως practice attempt και η ακρόαση να παρακάμψει τον εξεταστικό έλεγχο. Η ίδια διαδρομή ήταν προσβάσιμη μετά τον τερματισμό, πριν την επιστροφή σε εξάσκηση.

Η δρομολόγηση πλέον εξαρτάται από την ύπαρξη εξεταστικής συνεδρίας. Ο ExamEngine απορρίπτει ληγμένη/τερματισμένη συνεδρία. Η ακρόαση γραπτής απάντησης απαιτεί ρητή επιστροφή σε εξάσκηση. Το managed Windows audit καλεί τις πραγματικές Replay, Submit και PreviewAnswer για λήξη πριν τον timer και για ολοκληρωμένη εξέταση: έξι έλεγχοι χωρίς πραγματική έξοδο ήχου, χωρίς νέα απάντηση ή μεταβολή ιστορικού. Το pipeline απαιτεί και τις έξι εγγραφές.

## Στατιστικά και αποθηκευμένα δεδομένα

Η βαθμολόγηση ρυθμικής αναπαραγωγής επιτρέπει επιτυχή απάντηση με 80–99%. Η ανάλυση και η μέση βαθμολογία μετέτρεπαν κάθε επιτυχή απάντηση σε 100%. Πλέον διατηρούν το πραγματικό ποσοστό. Μόνο παλιά σωστή εγγραφή με απόν Percentage (τιμή 0 κατά τη φόρτωση) ερμηνεύεται ως 100%, για συμβατότητα.

Η επαναφορά εξέτασης απορρίπτει null entries, ελλιπείς ερωτήσεις, απουσία προηγούμενων απαντήσεων, αλλοιωμένα μεταδεδομένα απάντησης και ασυμφωνία επιπέδου ως ελεγχόμενο σφάλμα δεδομένων. Το αρχικό αρχείο διατηρείται. Οι εξετάσεις δεν αποτελούν σύστημα ασφαλούς επιτήρησης· ο έλεγχος προστατεύει από ασυνέπεια/αλλοίωση τοπικών δεδομένων.

## Αποδοχή

Απαιτούνται οι παλιοί έλεγχοι και οι νέες παλινδρομήσεις Linux/Windows, UIA πέντε καρτελών, πραγματική δημιουργία/δοκιμή πακέτων και ανακατασκευή Source ZIP πριν από νέο δημοσιευμένο preview. Η πραγματική NVDA/Windows 11 χρήστη/φυσική κάρτα και ακρόαση παραμένουν ανεπιβεβαίωτα. Το πρόγραμμα δεν χαρακτηρίζεται τελική 1.0.0.
