# Ακριβές σημείο συνέχισης προς 1.0.0

Η μουσική υλοποίηση παραμένει 0.5.0, με 28 κατηγορίες, έξι επίπεδα, εξετάσεις και Maestro CF-3. Δεν δηλώνεται ολοκληρωμένη 1.0.0.

1. Διάβασε UIA-ROOT-CAUSE.md, ACCEPTANCE-PROTOCOL.md και KNOWN-LIMITATIONS.md. Η παλιά διάγνωση «λείπει από τον κώδικα η πέμπτη καρτέλα» απορρίφθηκε: είναι ζήτημα native/virtual UIA fragment διασύνδεσης και αναπαράγεται χωρίς κώδικα εφαρμογής.
2. Το GUI/typed UIA client χρησιμοποιούν .NET 10 LTS, SDK 10.0.402. Core/Audio/tests παραμένουν net8.0 και απαιτούν .NET 8 runtime (SDK 8.0.426 επίσης εγκατεστημένο). 61 Linux tests πέρασαν μετά τη μετάβαση. Windows core: 53 tests. Ο ανεξάρτητος UIA client πέρασε 18 ελέγχους στο run 40083227118. Τα πλήρη keyboard checks βρίσκονται ακόμη σε σταθεροποίηση: τελευταία διόρθωση PowerShell IntPtr στο commit 461dc45. Έλεγξε το πιο πρόσφατο πραγματικό run, μην συμπεράνεις PASS από τις προηγούμενες μερικές επιτυχίες.
3. Τρέξε από desktop `./scripts/cloud-check.sh --maestro /workspace/.music-tools/maestro-private-piano/maestro.studio-piano.json --soundfont /tmp/music-test.sf2 --report artifacts/tests-0.5.0.json` όταν τα private inputs υπάρχουν. Μην τα αναδιανείμεις. Χωρίς αυτά δήλωσε integrations NOT RUN.
4. Το Windows workflow χτίζει, εκτελεί typed UIA και πραγματικά πλήκτρα πριν από packaging, επανελέγχει το published EXE και επιτρέπει μόνο μετά GitHub prerelease με μοναδικό tag v0.5.0-preview.<run_number>. Δεν επιτρέπεται continue-on-error στο UIA. Reports δημοσιεύονται στα codex/pets-ci-<run-id> branches ακόμη κι όταν υπάρχει FAIL.
5. Μόλις ολοκληρωθεί ο πλήρης P0 έλεγχος, πρόσθεσε/τρέξε Windows installer/portable smoke checks και επαλήθευσε πραγματική λήψη από GitHub Releases με SHA-256. Τα παλιά downloads/0.5.0 binaries παραμένουν ιστορικά και ΔΕΝ βαφτίζονται διορθωμένα· χρησιμοποίησε το νέο πραγματικό prerelease όταν υπάρχει.
6. Επόμενη χρήσιμη επαλήθευση ήχου: ο πραγματικός Windows Media Foundation FLAC decoder του PianoSetupDialog, ιδιωτική προετοιμασία Maestro και PCM integration στο Windows runner. Δεν έχει ακόμη εκτελεστεί. NVDA/φυσική κάρτα/επαγγελματική ακρόαση χρειάζονται πραγματική αποδοχή.
7. Πριν από 1.0.0 ολοκλήρωσε τα πραγματικά ανοικτά scope θέματα: πλήρης τεκμηριωμένη ABRSM syllabus αντιστοίχιση, απαιτούμενη μορφή σολφέζ/αναπαραγωγής, παιδαγωγική και χειροκίνητη NVDA/ήχου επαλήθευση. Μη συμπληρώσεις manual success flags χωρίς δοκιμές. `python scripts/release-readiness.py --output artifacts/readiness.json --require-final` πρέπει να απορρίπτει ατεκμηρίωτη τελική έκδοση.
8. Διατήρησε όλα τα παλιά checkpoints και τον υπάρχοντα κλάδο codex/pets-delivery. Μη δημιουργήσεις νέο έργο/worktree. Ενημέρωσε το cloud install/start draft για SDK 10 και 8: η παλιά αποθηκευμένη εγκατάσταση παραμένει SDK 8 μόνο.
