# Ακριβές σημείο συνέχισης προς 1.0.0

Η ανάπτυξη παραμένει **0.5.0** με 28 κατηγορίες/έξι επίπεδα. Το native UIA ζήτημα διορθώθηκε και οι Windows δοκιμές πέρασαν. Δεν βαφτίζεται η εφαρμογή 1.0.0 χωρίς τα υπόλοιπα πραγματικά κριτήρια.

1. Χρησιμοποίησε τον υπάρχοντα checkout και κλάδο codex/pets-delivery. Μην ξεκινήσεις νέο έργο/worktree και μην αφαιρέσεις παλιά παραδοτέα.
2. Διάβασε UIA-ROOT-CAUSE.md, PIANO-FIDELITY.md, ACCEPTANCE-PROTOCOL.md, VALIDATION.md και KNOWN-LIMITATIONS.md. Τα ελάχιστα fixtures απομόνωσαν το πρόβλημα στο mixed native/virtual fragment του WinForms, όχι σε απουσία καρτέλας. Η διόρθωση συνδυάζει native MSAA child IDs, ρητό UIA header model και τεκμηριωμένο HwndOverride για το περιεχόμενο.
3. Toolchain: SDK 10.0.402/.NET 10 GUI και UIA client· Core/Audio/tests net8.0 με runtime 8 (SDK 8.0.426 επίσης εγκατεστημένο). Το cloud setup draft ενημερώθηκε για εγκατάσταση και των δύο, με επίσημα SHA-512. Η δημοσίευση νέου snapshot ρυθμίσεων ανήκει στον χρήστη/περιβάλλον και δεν έχει επαληθευτεί από νέο task.
4. Από desktop: `./scripts/cloud-check.sh --maestro /workspace/.music-tools/maestro-private-piano/maestro.studio-piano.json --soundfont /tmp/music-test.sf2 --report artifacts/tests-0.5.0.json` εφόσον υπάρχουν τα private inputs. Πέρασαν 63 Linux checks. Μην παρουσιάσεις μη διαθέσιμα integrations ως PASS και μην αναδιανείμεις samples.
5. Windows pipeline: core 55, typed UIA 20, keyboard 19, real installer/portable/standalone smoke, ιδιωτικό download/Media Foundation decode 794 samples, SHA-256 PCM σύγκριση και 28 renders στη .NET 10, core/Maestro 62. Το τελευταίο πλήρες αποτέλεσμα ελέγχεται στο GitHub Actions. Δεν επιτρέπεται continue-on-error στο P0. Τα JSON διατηρούνται σε codex/pets-ci-<run-id> branches.
6. Επιτυχημένο pipeline δημοσιεύει αληθινό non-draft GitHub prerelease v0.5.0-preview.<run_number>. Τα παλιά downloads/0.5.0 binaries παραμένουν ιστορικά. Για χρήστη προτίμησε το νέο GitHub Release και επαλήθευσε πραγματική HTTPS λήψη/SHA-256. Το portable/standalone/Source ZIP δεν περιέχει ιδιωτικά δείγματα. Τοπική ενιαία παράδοση: deliverables/FINAL, ιστορικά snapshots διατηρούνται ξεχωριστά.
7. Επόμενη ουσιαστική δουλειά προς 1.0: πραγματική αποδοχή Windows 11/NVDA/κάρτας/ακρόασης και διόρθωση ευρημάτων, πλήρης τεκμηριωμένη αντιστοίχιση ABRSM tasks, τυχόν απαιτούμενη φωνητική/οργανική αναπαραγωγή (τώρα γραπτό/self-guided solfege) και παιδαγωγικός έλεγχος προχωρημένης πολυφωνίας. Δεν μετατρέπεις τις ανεπίσημες difficulty profiles σε δήθεν πλήρεις επίσημες εξετάσεις.
8. `python scripts/release-readiness.py --output artifacts/readiness.json --require-final` πρέπει να απορρίπτει ατεκμηρίωτη 1.0.0. Μην συμπληρώσεις NvdaPassed/AudioHardwarePassed/ProfessionalListeningPassed/UserDownloadPassed/CurriculumScopeAccepted χωρίς την αντίστοιχη πραγματική, τρέχουσα αποδοχή.
