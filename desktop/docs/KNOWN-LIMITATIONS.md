# Γνωστοί περιορισμοί πριν από τελική 1.0.0

1. Πραγματικά Windows Server CI έλεγξαν GUI/UIA, keyboard, εγκατάσταση/standalone και Media Foundation piano preparation. Δεν έχει δοκιμαστεί ο προσωπικός Windows 11 υπολογιστής, πραγματικό NVDA, φυσικό WASAPI/ASIO endpoint ή επαγγελματική ακρόαση. Απαιτείται το χειροκίνητο acceptance checklist.
2. Τα ABRSM-inspired προφίλ δεν είναι πλήρης προσομοίωση κάθε επίσημου syllabus task, δεν αξιολογούν επίσημη φωνητική εξέταση και δεν πιστοποιούν Grade. Απαιτείται τεκμηριωμένη αντιστοίχιση syllabus για ισχυρότερο ισχυρισμό.
3. Το σολφέζ είναι fixed-do με γραπτή απάντηση και προσωπική σύγκριση. Η φωνή/μικρόφωνο δεν καταγράφεται ή βαθμολογείται.
4. Οι πολυφωνικές γραμμές είναι ανεξάρτητες σε ρυθμό/register, όχι πλήρης μηχανή αυστηρής αντίστιξης. Δεν επιβάλλονται όλοι οι SATB κανόνες σε όλες τις αρμονικές διαδοχές.
5. Το πιάνο είναι πραγματικό Maestro CF-3, αλλά ο adapter δεν υλοποιεί πλήρη ARIA, half-pedal/sostenuto/resonance ή hardware MIDI pedal/input. Η φυσικότητα/ισορροπία χρειάζεται ακρόαση. Δεν χρησιμοποιείται ψεύτικος oscillator ως εναλλακτικό grand piano.
6. Επιλεγμένο τμήμα επανεπιτίθεται σε νότα που κρατούσε από πριν την αρχή του. Δεν ισχυριζόμαστε sample-exact seek μέσα σε sustaining note.
7. Οι εξετάσεις είναι τοπικές εκπαιδευτικές συνεδρίες, όχι αδιάβλητη επιτήρηση. Τα JSON του χρήστη δεν είναι κρυπτογραφημένα. Κράτησε backups.
8. Τα πακέτα δεν είναι ψηφιακά υπογεγραμμένα. Windows x64· ARM/άλλα λειτουργικά δεν έχουν ελεγχθεί.
9. Τα ιστορικά πακέτα 0.2–0.4 διατηρούνται ως development checkpoints. Για πραγματική δοκιμή προτίμησε 0.5 ή νεότερη: στη 0.5 διορθώθηκε κίνδυνος stale cache στην πρώτη ακρόαση νέας ερώτησης.
10. Το ότι υπάρχουν τοπικά πακέτα ή source commit δεν αποδεικνύει δυνατότητα λήψης από τον υπολογιστή του χρήστη. Η εξωτερική παράδοση πρέπει να επαληθευτεί ξεχωριστά, χωρίς κατασκευασμένα public URLs.

11. Οι keyboard δοκιμές χρησιμοποιούν πραγματικά Tab/βέλη/Ctrl+Tab/F1. Δεν ισχυρίζονται επιτυχή εκτέλεση κάθε προγραμματιστικής SetFocus στα standard WinForms controls: το ComboBox SetFocus του runtime δεν έφερε πραγματική εστίαση στο συγκεκριμένο test. Η πλοήγηση με Tab και η ανάγνωση/αλλαγή τιμής ελέγχθηκαν ξεχωριστά. Πραγματική συμπεριφορά NVDA object navigation παραμένει προς έλεγχο.
