# Πρωτόκολλο αποδοχής και παραδοχές

Η ένδειξη PASS απαιτεί πραγματική εκτέλεση, καταγεγραμμένο commit, περιβάλλον, αποτέλεσμα και αρχείο τεκμηρίων. NOT RUN, FAIL και BLOCKED παραμένουν διακριτά. Δεν μετατρέπουμε προγραμματιστικό έλεγχο σε πιστοποίηση NVDA ή ακουστικής ποιότητας.

| Προτεραιότητα | Κριτήριο ολοκλήρωσης | Απόδειξη |
|---|---|---|
| P0: Windows UIA | Ακριβώς οι πέντε ονομασμένες καρτέλες, μοναδικά IDs, δυνατότητα επιλογής όλων και προσβάσιμο περιεχόμενο | Εξωτερικό UIA audit σε Windows, χωρίς αγνόηση αποτυχίας |
| P0: Πληκτρολόγιο | Ctrl+Tab και Ctrl+Shift+Tab περνούν και επιστρέφουν από τις πέντε καρτέλες· F1 εστιάζει στις Οδηγίες· Tab/Shift+Tab δεν παγιδεύουν την εστίαση | Αυτοματοποιημένη πραγματική είσοδος πλήκτρων και καταγραφή focused element, συν χειροκίνητη NVDA αποδοχή |
| P1: Θεωρία/βαθμολόγηση | Διατηρούνται όλοι οι υφιστάμενοι έλεγχοι· νέες λειτουργίες έχουν ανεξάρτητες αναφορές και περιπτώσεις λανθασμένων απαντήσεων | Core tests Linux/Windows και αναφορές ανά commit |
| P1: Πρόοδος | Ρυθμίσεις, απαντήσεις και εξετάσεις επανέρχονται· άκυρα δεδομένα προστατεύονται | Round-trip, corruption/recovery tests |
| P2: Ήχος | Όλες οι κατηγορίες χρησιμοποιούν τον κοινό renderer, σωστό timing/pitches/velocity/sustain/release και πεπερασμένο PCM | Πραγματικό Maestro integration· ξεχωριστή επαγγελματική ακρόαση/κάρτα |
| P3: Παράδοση | EXE, Setup, Portable, Source, οδηγίες και SHA-256 σε μη draft GitHub prerelease | Επιτυχής Windows pipeline με P0 gate και πραγματική HTTPS λήψη που συμφωνεί με SHA-256 |
| Τελική 1.0.0 | Όλα τα παραπάνω και αποδοχή Windows 11/NVDA/ακρόασης, επίλυση ανοικτού scope | Συμπληρωμένο αποδεικτικό αποδοχής και επιτυχές release-readiness --require-final |

## Σταθερές παραδοχές

- Στόχος Windows 11 x64, τοπική λειτουργία μετά την πρώτη ιδιωτική εγκατάσταση Maestro. Δεν αναδιανέμονται τα περιορισμένα δείγματα.
- Οι προσομοιώσεις ABRSM είναι ανεξάρτητες και ανεπίσημες. Η πλήρης αντιστοίχιση με το ισχύον syllabus παραμένει ανοικτή μέχρι πραγματική τεκμηρίωση.
- Το υπάρχον σολφέζ δέχεται γραπτές απαντήσεις· δεν αποτελεί αναγνώριση ή βαθμολόγηση φωνής.
- Καμία αποτυχία UIA δεν παρακάμπτεται με μείωση του αναμενόμενου αριθμού καρτελών ή προαγωγή σε 1.0.0.
- Κάθε νέα παράδοση διατηρεί προηγούμενα πακέτα και μοναδικό release tag. Το αρχείο που υπάρχει μόνο στο cloud δεν θεωρείται παραδομένο.
