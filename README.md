# Professional Ear Training Studio

Native Windows 11 x64, ελληνικά, πληκτρολόγιο/NVDA σχεδιασμός και πραγματικό Maestro Concert Grand Yamaha CF-3.

Η υλοποίηση προχώρησε διαδοχικά έως **0.5.5**, με διαστήματα/συγχορδίες, πτώσεις/κλίμακες/τρόπους/ρυθμό, ντικτέ/σολφέζ, πολυφωνία/χρωματική/σειρές και ανεξάρτητες εκπαιδευτικές εξετάσεις. Η τελική επαγγελματική **1.0.0 δεν δηλώνεται ολοκληρωμένη** χωρίς Windows/NVDA/ήχο acceptance.

[Νέος επαληθευμένος εγκαταστάτης Windows](https://github.com/kyriakoslouka-crypto/music-app/releases/download/v0.5.5-preview.66/ProfessionalEarTrainingStudio-0.5.5-Setup.exe) · [Όλα τα νέα παραδοτέα](https://github.com/kyriakoslouka-crypto/music-app/releases/tag/v0.5.5-preview.66) · [Αναφορά παράδοσης και ακριβές σημείο συνέχισης](downloads/0.5.5/README.md) · [Οδηγίες](desktop/README.md) · [Πραγματικές δοκιμές](downloads/0.5.5/README.md#πραγματικοί-έλεγχοι) · [Περιορισμοί](desktop/docs/KNOWN-LIMITATIONS.md) · [Συνέχιση προς 1.0](desktop/docs/CONTINUE-TO-1.0.md).

`desktop/deliverables/releases/` διατηρεί πλήρη versioned πακέτα, source ZIP, οδηγίες και tests. Το τοπικό filesystem δεν ισοδυναμεί με δημόσια λήψη. Η εξωτερική παράδοση τεκμηριώνεται χωριστά. Τα δείγματα πιάνου δεν αναδιανέμονται· εγκαθίστανται ιδιωτικά από τη δημοσιευμένη πηγή.

Το παλιό root web prototype διατηρείται για ιστορική αναφορά. Η κύρια εφαρμογή είναι το solution στο `desktop/`.
