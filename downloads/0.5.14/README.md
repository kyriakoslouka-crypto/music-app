# Professional Ear Training Studio 0.5.14 — οκτάβες και ανεξάρτητες αλλοιώσεις

[Εγκαταστάτης Windows](https://github.com/kyriakoslouka-crypto/music-app/releases/download/v0.5.14-preview.81/ProfessionalEarTrainingStudio-0.5.14-Setup.exe) · [Όλα τα παραδοτέα](https://github.com/kyriakoslouka-crypto/music-app/releases/tag/v0.5.14-preview.81)

## Χειρισμός

1. Εγκατάστησε τη 0.5.14, διατηρώντας τις προσωπικές φωνές/ρυθμίσεις. NVDA+T διαβάζει την έκδοση στον τίτλο.
2. Στον ισοκράτη Ctrl+L ξεκινά τον ζωντανό χειρισμό. Πάνω/κάτω: φθόγγοι, δεξιά/αριστερά: φωνές, **Shift+πάνω/κάτω: ίδιος φθόγγος μία οκτάβα ψηλότερα/χαμηλότερα**. Μέσα στους 15 υπάρχοντες φθόγγους, χωρίς κυκλική μετάβαση στα όρια. Tab επιστρέφει στα κανονικά πεδία, Esc σταματά.
3. Επίλεξε π.χ. Ζω και με Tab βρες «Ελεύθερη πρόσθετη αλλοίωση επιλεγμένου φθόγγου σε μόρια». Δέχεται **−7200 έως +7200**, με δύο δεκαδικά. Μετακινεί μόνο τα Ζω σε όλες τις οκτάβες. Οι άλλοι έξι φθόγγοι δεν μεταβάλλονται. Η γενική μεταφορά και η σειρά διαστημάτων είναι διαφορετικά πεδία.
4. Η προσωπική αποθήκευση ανά ήχο και το παράθυρο Εφαρμογή/Ακύρωση διατηρούνται. Οι πρόσθετες αλλοιώσεις δεν απαιτούν άθροισμα 72· η σειρά επτά βασικών διαστημάτων εξακολουθεί να ορίζει οκτάβα 72 μορίων.

Τα αριθμητικά όρια ρύθμισης δεν σημαίνουν ότι η φωνή μπορεί να αναπαράγει κάθε ακραία τιμή. Παραμένει ο έλεγχος 35–2000 Hz και της διαθέσιμης έκτασης δειγμάτων, με σαφές μήνυμα. Δεν γίνεται σιωπηλή προσαρμογή άλλων φθόγγων.

## Πραγματικοί έλεγχοι

Source commit `1a9152f341398818a7c69b432cb0c72415204714`. [Επιτυχές Windows workflow](https://github.com/kyriakoslouka-crypto/music-app/actions/runs/40284999529).

- Linux: 131 πλήρεις δοκιμές με Maestro/SF2 και 198 ιδιωτικά MP3, και 9 δοκιμές εξόδου ήχου, καμία αποτυχία.
- Windows: 118 βασικές δοκιμές, 129 στην επικαλυπτόμενη παραλλαγή Maestro και 9 εξόδου ήχου, καμία αποτυχία.
- Νέα μαθηματική δοκιμή: Ζω +90 μορίων αλλάζει αποκλειστικά τα Ζω, με ακριβή αναλογία συχνότητας. Επαναφορά JSON των ±7200, απόρριψη μη πεπερασμένων/εκτός ορίων τιμών.
- Δοκιμή όλων των 15 φθόγγων/δύο κατευθύνσεων: αλλαγή οκτάβας διατηρεί φθόγγο, ακριβώς διπλασιάζει/υποδιπλασιάζει τη συχνότητα και δεν τυλίγεται στα όρια.
- Native Windows GUI με προσομοιωμένη έξοδο: Shift+βέλη, μία μόνο έναρξη συσκευής, +90 από αριθμητικό πεδίο και JSON επαναφορά, αμετάβλητες άλλες νότες. `OctaveArrowsPassed=true`, `IndependentLargeAlterationsPassed=true`, `DeviceOpens=1`, `DeviceReopenCount=0`.
- Διατηρούνται 24 typed UIA, 26 keyboard έλεγχοι, επτά καρτέλες, ανακοίνωση ελληνικών ονομάτων με πραγματική διεργασία NVDA/σιωπηλό synthesizer στον runner, Maestro PCM/MP3, εγκατάσταση/Portable/standalone και Source ZIP rebuild.
- Και οι 29 αυτοματοποιημένες κατηγορίες ετοιμότητας πέρασαν. Έγινε εξωτερική HTTPS λήψη και SHA-256 και των 51 παραδοτέων, Portable/Source CRC, αντιστοίχιση κρίσιμου πηγαίου κώδικα και επανυπολογισμός readiness.

[Πραγματική native αναφορά](ison-live-check.json) · [Ακεραιότητα λήψης](DELIVERY-VERIFICATION.json) · [Ετοιμότητα](READINESS.json).

Η νέα λειτουργία δεν έχει ελεγχθεί από άνθρωπο με NVDA ούτε με φυσική κάρτα ήχου/ακρόαση. `ReadyForWindows11Trial=true`, `ReadyForProfessionalFinal=false`. Δεν δηλώνεται ολοκλήρωση ολόκληρου του προγράμματος 1.0. Οι φωνές/δείγματα παραμένουν εκτός δημόσιων πακέτων. Η προσωπική αποστολή σε φίλους δεν μεταφέρει δικαιώματα ξένων ηχογραφήσεων.
