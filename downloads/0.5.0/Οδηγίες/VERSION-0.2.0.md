# Version 0.2.0 — θεωρία και ρυθμός

Νέες πραγματικές κατηγορίες στο native πρόγραμμα:

- Αυθεντική τέλεια (PAC: V και I σε βασική θέση, τονική στη σοπράνο), αυθεντική ατελής (IAC), ημίπτωση, πλάγια και απατηλή πτώση. Ακούγεται I–V–I ή i–V–i ως πλαίσιο, παύση, έπειτα οι δύο αξιολογούμενες συγχορδίες. Στην ελάσσονα η δεσπόζουσα χρησιμοποιεί προσαγωγέα. Ελέγχθηκαν και οι παράλληλες πέμπτες/οκτάβες στις αξιολογούμενες τετράφωνες συνδέσεις.
- 11 τύποι κλιμάκων: μείζων, φυσική/αρμονική/μελωδική ελάσσων, χρωματική, ολοτονική, μείζων/ελάσσων πεντατονική, δύο ελαττωμένες και αυξημένη εξατονική. Η κλασική μελωδική ελάσσων κατεβαίνει ως φυσική.
- Επτά εκκλησιαστικοί τρόποι. Το κέντρο είναι η πρώτη/τελευταία νότα. Ionian/major και Aeolian/natural-minor εξετάζονται σε διαφορετικές κατηγορίες ώστε να μη ζητείται αδύνατη ακουστική διάκριση εναρμόνιων ονομάτων.
- Ρυθμικά σχήματα με παραστίξεις, συγκοπή, παύσεις και δέκατα έκτα.
- 12 μέτρα/ομαδοποιήσεις: 2/4, 3/4, 4/4, 6/8, 9/8, 12/8, 5/8 (2+3 ή 3+2), 7/8 (τρεις ομαδοποιήσεις), 8/8 (3+3+2). Οι ισχυροί/δευτερεύοντες παλμοί ακούγονται με διαφορετική δυναμική. Η διάκριση βασίζεται στη δηλωμένη ομαδοποίηση και το καθορισμένο BPM, όχι σε αυθαίρετη ονομασία άτονων κτύπων.
- Ρυθμική υπαγόρευση: μία μπάρα εισαγωγής, έπειτα γραπτή απάντηση μόνο με πληκτρολόγιο. Διάρκειες `1/4`, `1/8`, `1/16`, `1/2`, `1/1`, τελεία για παράστιξη, `r` για παύση και `|` ανά μέτρο. Παράδειγμα 4/4: `1/4 1/8 1/8 1/2`. Η ισοδύναμη γραφή δεσμών χωρίς κενά (`1/4+1/8`) γίνεται δεκτή ως `1/4.`.
- Ρυθμική αναπαραγωγή: F8 σε κάθε έναρξη και επιπλέον στο τέλος της τελευταίας διάρκειας· Ctrl+Enter βαθμολογεί χρονικές αποστάσεις στο επιλεγμένο BPM. Δεν καταγράφεται μικρόφωνο, διάρκεια κρατήματος πλήκτρου ή φωνή. Τα επίπεδα καθορίζουν διαφορετική ανοχή χρονισμού.

Η επιλογή τονικότητας στις νέες κλίμακες/τρόπους ορίζει το τονικό κέντρο, όχι την απάντηση ποιότητας. Στις πτώσεις ορίζει και μείζονα/ελάσσονα. Το μέτρο ρυθμικής υπαγόρευσης/κτυπημάτων και το πλήθος μέτρων επιλέγονται στις Ρυθμίσεις. Η αναγνώριση μέτρων παίζει τουλάχιστον δύο μέτρα. Το πεντάλ δεν εφαρμόζεται σε ρυθμικές ασκήσεις, ώστε να διατηρούνται οι παύσεις/αρθρώσεις.

Πραγματική επαλήθευση Linux: 35 tests με το Maestro/SF2, περιλαμβανομένων 2.520 παραγωγών νέων κατηγοριών, reference θεωρίας, timing, γραπτής/κινητικής βαθμολόγησης, snapshots αποθήκευσης και πραγματικού sample rendering κάθε νέας κατηγορίας. Το build πέρασε με 0 warnings/errors. Windows UIA/NVDA, πραγματική εγκατάσταση, driver/audio output, input latency και ακρόαση παραμένουν μη δοκιμασμένα εδώ. Το runtime report γράφεται με `--report` και περιλαμβάνεται στα παραδοτέα.

Προσβασιμότητα οδηγιών: στις νέες ακολουθίες Ctrl+N δημιουργεί την ερώτηση και ανακοινώνει την οδηγία **χωρίς να ξεκινά αμέσως μουσική**. Ctrl+R ξεκινά την πρώτη ακρόαση όταν είναι έτοιμος ο χρήστης. Ctrl+I σταματά τη μουσική και εστιάζει την οδηγία για ανάγνωση. Αυτό αποτρέπει να χαθεί η εξήγηση του τονικού πλαισίου/εισαγωγικού μέτρου κάτω από ήχο. Οι παλιές τέσσερις κατηγορίες διατηρούν την προηγούμενη έναρξη.
